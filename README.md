# data266-1605

Private submission repository for DATA 266 (SID4 = 1605), per Section 0.3 of the standing
assignment requirements. Each homework lives in its own top-level folder and is marked with a
`hwN` (or `hwN-5` for GPU Labs) git tag at submission time.

## Layout

- `hw1/` — Homework 1: autoregressive models, PyTorch/TensorFlow diabetes-dataset neural
  networks, CUDA matrix multiplication. See `hw1/METRICS.md`, `hw1/RUN_LOG.txt`, and
  `hw1/AI_USE.md` for the required standing artifacts.
